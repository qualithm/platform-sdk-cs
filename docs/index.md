# Qualithm.Platform

The API reference for the C# client of the Qualithm Platform API, built by docfx from its XML doc
comments. Start with [`PlatformClient`](api/Qualithm.Platform.PlatformClient.yml) and
[`PlatformException`](api/Qualithm.Platform.PlatformException.yml); the generated `…Api` classes
are in [`Qualithm.Platform.Api`](api/Qualithm.Platform.Api.yml) and their types in
[`Qualithm.Platform.Model`](api/Qualithm.Platform.Model.yml).
